# Senlo-Wanhsiang (森罗万象)

🎨 **森罗万象** *A powerful, open-source file format converter named after the Chinese idiom "Vast and All-Inclusive" (Senlo-Wanhsiang).*

---

## 📖 Introduction / 简介

**Senlo-Wanhsiang** 是一个用 Java 开发的通用文件格式转换软件。正如其名“森罗万象”，本项目的愿景是打造一个包罗万象、功能全能的转换工具，帮助用户轻松应对几乎所有常见的文件格式转换需求。

**Senlo-Wanhsiang** is a universal file format converter built with Java. True to its name "Senlo-Wanhsiang" (everything in the universe), this project aims to provide a versatile and comprehensive solution, helping users seamlessly convert almost any file format.

---

## ✨ Features / 核心特性

* **🎵 Audio Conversion (音频转换):** Supports almost all audio formats (e.g., MP3, WAV, FLAC, AAC, OGG, etc.). / 支持几乎所有音频格式的互相转换。
* **🎬 Video Conversion (视频转换):** Supports almost all video formats (e.g., MP4, MKV, AVI, MOV, FLV, etc.). / 支持几乎所有视频格式的互相转换。
* **📦 Archive Conversion (压缩包转换):** Supports conversion between various archive formats (e.g., ZIP, RAR, 7Z, TAR, etc.). / 支持各种压缩包格式之间的互相转换。
* **☕ Java Powered:** Cross-platform, stable, and highly efficient. / 基于 Java 构建，跨平台、稳定且高效。
* **🔓 Open Source:** Proudly free and open under the GPLv3 license. / 完全开源，基于 GPLv3 协议保障社区自由。
